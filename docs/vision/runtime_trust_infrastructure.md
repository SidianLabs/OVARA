# Runtime Trust Infrastructure

> **Historical snapshot — not the current plan.** Kept for history; it may
> describe code that has since changed or been removed. For what Ovara does
> and promises today, see [docs/GUARANTEES.md](../GUARANTEES.md) and [docs/box.md](../box.md).

Runtime trust infrastructure is the layer that determines whether a machine
action should happen now, under these conditions, with this authority, and in
this environment.

Core properties:

- real-time policy evaluation
- continuous trust calculation
- execution interception
- provenance capture
- behavior-aware enforcement

This is the foundation Ovara intends to own.
