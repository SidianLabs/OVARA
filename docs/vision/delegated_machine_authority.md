# Delegated Machine Authority

> **Historical snapshot — not the current plan.** Kept for history; it may
> describe code that has since changed or been removed. For what Ovara does
> and promises today, see [docs/GUARANTEES.md](../GUARANTEES.md) and [docs/box.md](../box.md).

Delegated machine authority is the process by which a human or organization
grants a bounded capability to an autonomous system.

Ovara's position is that delegation must always include:

- scope
- duration
- target resource bounds
- execution pathway constraints
- approval requirements
- attribution chain
- revocation path

Authority without those properties becomes indistinguishable from uncontrolled
service-account sprawl.
