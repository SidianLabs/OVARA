# Trust Model

Ovara computes trust across multiple dimensions:

- identity trust
- capability trust
- behavioral trust
- environmental trust
- provenance trust

## Trust State

Trust is a score plus explanation, not a binary flag.

Inputs:

- recent anomaly signals
- runtime attestation state
- delegation depth
- policy violations
- environmental posture

Outputs:

- decision influence
- approval requirement
- containment recommendations
