# Governance Model

Ovara's governance — who decides, the RFC process for contract changes, the
compatibility promise, and the deprecation policy — now lives in
[`GOVERNANCE.md`](../../GOVERNANCE.md) at the repository root, with the RFC
mechanics in [`spec/rfcs/`](../../spec/rfcs/README.md).

The principle is unchanged from the original note: open design docs and ADRs,
public roadmap signals for the OSS components, and compatibility promises for
the policy and receipt schemas.
