# V1 Threat Priorities

V1 security should prioritize threats that are both likely and actionable in
agentic coding and DevOps environments.

## Priority 1

- prompt-injection-driven shell misuse
- unauthorized Git or GitHub mutation
- deployment triggering outside approved environments
- stolen or replayed capability leases
- operator approval spoofing

## Priority 2

- recursive sub-agent execution without delegation control
- secret exposure through overly broad shell capability
- policy bypass through incomplete interception coverage

## Later Research

- distributed multi-agent coordination attacks
- adaptive learned trust modeling
- autonomous containment across heterogeneous infrastructures
