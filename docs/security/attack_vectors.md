# Attack Vectors

Primary attack vectors:

- prompt injection into tool-using agents
- stolen or replayed capability leases
- hidden multi-step escalation
- malicious code introduced via autonomous development loops
- operator approval spoofing

## V1 Focus

The first shipping defenses should concentrate on engineering and deployment
workflows. That means prioritizing shell misuse, repository mutation, approval
spoofing, and deployment abuse over more speculative cross-domain attacks.
