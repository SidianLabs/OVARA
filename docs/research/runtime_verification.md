# Runtime Verification

> **Historical snapshot — not the current plan.** Kept for history; it may
> describe code that has since changed or been removed. For what Ovara does
> and promises today, see [docs/GUARANTEES.md](../GUARANTEES.md) and [docs/box.md](../box.md).

Runtime verification should blend cryptographic proofs, policy snapshots,
environment attestation, and signed receipts so post-hoc analysis can prove not
only what happened, but under what authority and trust state it happened.
