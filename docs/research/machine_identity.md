# Machine Identity

> **Historical snapshot — not the current plan.** Kept for history; it may
> describe code that has since changed or been removed. For what Ovara does
> and promises today, see [docs/GUARANTEES.md](../GUARANTEES.md) and [docs/box.md](../box.md).

The internet lacks a standard equivalent of a passport for autonomous systems.
Ovara's research direction is to combine cryptographic identity, trust metadata,
and delegated capability proofs into a portable machine identity model.
