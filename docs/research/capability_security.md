# Capability Security

> **Historical snapshot — not the current plan.** Kept for history; it may
> describe code that has since changed or been removed. For what Ovara does
> and promises today, see [docs/GUARANTEES.md](../GUARANTEES.md) and [docs/box.md](../box.md).

Capability systems fit autonomous software because they constrain what a machine
can do at the moment of action rather than relying on broad ambient permissions.
Research focus: lease design, revocation latency, inheritance, and delegation
limits.
