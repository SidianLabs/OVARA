# Autonomous Security Research

> **Historical snapshot — not the current plan.** Kept for history; it may
> describe code that has since changed or been removed. For what Ovara does
> and promises today, see [docs/GUARANTEES.md](../GUARANTEES.md) and [docs/box.md](../box.md).

Autonomous systems require a shift from static perimeter controls to continuous
runtime judgment. Research priorities include long-horizon attacks, trust decay,
recursive coordination threats, and machine-directed exploit chaining.
