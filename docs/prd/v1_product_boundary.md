# V1 Product Boundary

This document exists to prevent scope creep.

## V1 Product

Ovara v1 is a runtime authorization and approval layer for autonomous coding
and deployment actions.

It includes:

- SDK interceptors
- runtime gateway
- policy evaluation
- capability checks
- approval workflows
- execution receipts
- local and hosted observability for those actions

## V1 Users

- AI coding platforms
- internal developer tool teams
- DevOps automation teams
- autonomous workflow platforms focused on engineering operations

## V1 Success Criteria

- one-day integration for TypeScript and Python users
- visible reduction in unauthorized or unsafe machine actions
- approval and audit workflows that security teams can understand
- credible path from local runtime to hosted control plane

## Not V1

- universal governance for every AI workflow
- trust graph infrastructure
- federated cross-organization machine identity
- probabilistic auto-blocking based on opaque ML signals
- full agent framework replacement
