# ovara-sdk

Python SDK for the Ovara Runtime Gateway.

## Usage

```python
import asyncio
from ovara_sdk import OvaraClient, ActionRequest

async def main():
    client = OvaraClient(base_url="http://localhost:8080", api_key="sk_...")
    try:
        # Advisory check: the gateway returns a DecisionResponse JSON object.
        decision = await client.check(
            ActionRequest(
                action_type="shell",
                resource="shell:ls",
                environment="local",
            )
        )
        print(decision["decision"])  # "allow" | "deny" | "escalate"
    finally:
        await client.aclose()

asyncio.run(main())
```

## Receipts

Gateway decision receipts (`GET /v1/receipts/{id}`) are HMAC-signed
server-side and are not client-verifiable. The receipt-verification
helpers (`verify_receipt`, `compute_receipt_digest`) verify *proxy*
receipts — the ed25519-signed chain produced by the Ovara egress proxy
(`proxy/internal/receipts`) — using the proxy's distributed public key.
Both receipt versions verify: v1 (`sig_v1`) and v2 (`"v":2`, `sig_v2`,
key id in `kid`). Build a receipt from a chain line with
`PortableReceipt.from_json(line)`. These check one receipt at a time;
chain order and links are checked by `ovara log --verify-only`. The test
vectors in `sdk/testdata/receipts_v2.json` are generated by the proxy.

## Tool guard

Wrap the functions your framework's tools run, and every call is decided
by the gateway before it runs, held for a person when policy says so, and
reported when it is done. The guard holds the agent token only.

```python
from ovara_sdk import ToolGuard, ToolDenied, ToolHeld

guard = ToolGuard("http://127.0.0.1:8080", api_key=AGENT_TOKEN,
                  agent="support-bot", framework="langchain", wait_seconds=60)

@guard.tool("send_email")
def send_email(to: str, subject: str, body: str) -> str: ...

async_tool = guard.wrap(fetch_page, "fetch_page")      # sync or async, kept as is
tool = guard.langchain(StructuredTool.from_function(delete_file))
```

A denied call raises `ToolDenied`; a call still waiting on a person after
`wait_seconds` raises `ToolHeld` with the approval id (set `wait_seconds=0`
to fail fast and call again later: the identical call gets the answer
back). `guard.last` is the record of the last call (decision, approval,
whether the outcome was recorded).
